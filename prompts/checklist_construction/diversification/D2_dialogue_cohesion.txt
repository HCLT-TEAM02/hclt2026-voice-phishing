<태스크 개요>

다음 정보가 제공됩니다.

1) 평가 대상 태스크에 관한 정보
2) 평가 태스크에서 검토하려는 상위 평가 차원
3) 해당 상위 차원을 구성하는 하위 차원과 각 하위 차원에 대한 Seed Question

당신의 임무는 상위 평가 차원을 종합적으로 평가할 수 있도록,
각 하위 차원에 대한 추가 평가 질문을 생성하는 것입니다.

각 추가 질문은 해당 하위 차원과 Seed Question의 평가 범위를 유지하면서도,
Seed Question과 서로 다른 관점에서 증강 대화를 검토해야 합니다.
이를 통해 동일한 평가 기준을 다양한 측면에서 확인할 수 있는
고품질 평가 질문 집합을 구성해야 합니다.


1) 평가 태스크 정보

평가 태스크 이름:
보이스피싱 증강 통화 품질 평가

평가 목적:
원본 보이스피싱 통화와 이를 바탕으로 생성된 증강 통화를 비교하여,
증강 통화가 원본의 핵심 의미와 사기 전략을 보존하면서
응집성 있고 자연스러운 한국어 통화로 변형되었으며,
원본 대비 충분한 표현 변화를 포함하는지를 평가합니다.

평가 대상 데이터:
- 원본 보이스피싱 통화 1개
- 해당 원본을 바탕으로 생성된 증강 통화 1개

평가 단위:
원본 통화와 증강 통화 한 쌍을 평가합니다.
서로 다른 증강본 1, 2, 3 사이의 상호 다양성은 평가하지 않습니다.

화자 정보:
화자는 S1, S2, S3 등의 번호로만 표시됩니다.
피해자 또는 사기범이라는 역할 정보는 명시적으로 제공되지 않습니다.
필요한 경우 원본 발화 내용을 바탕으로 각 화자의 기능적 역할을 파악해야 합니다.

별도 규칙 기반 검증:
JSON 형식, conversation_id, conversation_label, 필드명, idx 순서,
빈 문자열 여부, 화자 수 및 발화 수 조건과 같은 형식적 규칙은
별도의 프로그램으로 검사합니다.

따라서 이러한 형식적 조건을 평가하는 체크리스트 질문은 생성하지 마십시오.


2) 평가할 상위 차원

대화 응집성:
증강 통화의 발화와 사기 시나리오의 각 단계가 논리적이고 관련성 있게 연결되며,
대화의 주제가 일관되게 유지되는 정도


3) 하위 차원 및 Seed Questions

1. 논리적 흐름
- 증강 통화의 각 발화는 앞선 발화에서 논리적으로 이어지는가?

2. 관련성
- 각 발화가 직전 발화의 질문, 설명, 요청 또는 반응에 적절하게 대응하는가?

3. 단계 전개 연속성
- 사기 시나리오의 각 단계가 자연스러운 순서로 제시되는가?

4. 주제 유지
- 대화가 관련 없는 주제로 갑자기 전환되지 않는가?


<좋은 평가 질문 목록의 조건>

1. 하위 차원 정합성
생성된 모든 질문은 해당 하위 차원과 Seed Question이 정의한
평가 범위 안에 있어야 하며, 다른 평가 차원의 내용을 다루지 않아야 합니다.

2. 관점의 다양성
각 질문은 동일한 하위 차원을 유지하면서도 서로 다른 판단 관점,
확인 요소 또는 실패 양상을 평가해야 합니다.

3. 비중복성
생성된 질문은 Seed Question이나 다른 생성 질문을 단순히 바꾸어
표현해서는 안 되며, 각 질문이 구별되는 평가 정보를 제공해야 합니다.

4. 태스크 관련성과 관찰 가능성
각 질문은 보이스피싱 증강 대화의 품질 판단에 실질적으로 관련되어야 하며,
제공된 원본 대화와 증강 대화에서 직접 확인할 수 있는 내용을 평가해야 합니다.

5. 평가 범위의 균형
질문 목록은 특정한 한 측면에만 편중되지 않고, 해당 하위 차원에서
중요한 여러 측면을 균형 있게 다루어야 합니다.


<제약 조건>

- 각 하위 질문은 간단한 ‘예’ 또는 ‘아니요’로 답할 수 있어야 합니다.

- ‘예’라는 응답은 해당 증강 대화가 명시된 평가 기준을 더 잘 충족한다는 것을 의미해야 합니다.

- 각 질문은 하나의 차원 또는 하나의 개념만을 평가해야 합니다.

- 각 질문은 둘 이상의 주제나 개념을 동시에 묻지 않아야 합니다.
