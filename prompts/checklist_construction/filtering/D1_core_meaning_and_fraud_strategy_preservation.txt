<태스크 개요>

당신의 임무는 다음 기준에 따라 질문 목록에서 부적절한 질문을 제거하는 것입니다.


1) 평가 차원 정합성

- 평가 차원의 정의:
원본 통화의 보이스피싱 시나리오, 사기 수법, 핵심 행동 목표, 설득 흐름,
핵심 정보 및 화자별 기능적 역할이 증강 통화에서 보존되는 정도

- 주어진 평가 차원의 정의에서 벗어나는 질문을 제거하세요.

- 현재 평가 차원보다 다른 평가 차원과 더 밀접하게 관련된 질문을 제거하세요.


2) 중복성

- 다음에 해당하는 질문을 제거하세요.

  * 표현 방식이 다르더라도 동일하거나 매우 유사한 정보를 묻는 질문

  * 고유한 평가 정보를 추가하지 않으면서 매우 유사한 의미를 전달하는 질문


3) 질문 표현 및 세분성

- 다음에 해당하는 질문을 제거하세요.

  * 지나치게 과장된 표현을 사용하는 질문

  * 증강 대화의 전반적인 품질에 유의미한 영향을 미치지 않는
    지나치게 세부적이거나 사소한 요소에 초점을 맞춘 질문


4) 평가 태스크 맥락

- 태스크 이름:
  보이스피싱 통화 데이터 증강 품질 평가

- 목적:
  원본 보이스피싱 통화의 핵심 의미와 사기 시나리오를 유지하면서
  생성된 증강 대화의 품질 평가

- 핵심 평가 차원:
  핵심 의미 및 사기 전략 보존, 대화 응집성,
  자연스러움, 증강 다양성

- 필터링 후 남은 질문의 내용을 수정하거나 새로운 질문을 생성하지 마세요.

- 질문을 기존의 딕셔너리 형식으로 유지하세요.


5) 하위 차원 및 질문

{
  "사기 시나리오 보존": {
    generated_questions
  },
  "사기 수법 및 행동 목표 보존": {
    generated_questions
  },
  "핵심 설득 흐름 보존": {
    generated_questions
  },
  "새로운 핵심 정보 추가 없음": {
    generated_questions
  },
  "핵심 정보 보존": {
    generated_questions
  },
  "화자별 기능적 역할 보존": {
    generated_questions
  }
}


6) 출력 요구사항

- 출력 형식: JSON만 출력하세요.

- 구조:

{
  "하위 차원 이름": [
    "필터링 후 질문 1",
    "필터링 후 질문 2"
  ]
}


<중요 사항>

- 필터링 후 남은 질문의 내용을 수정하지 마세요.

- 새로운 질문을 생성하지 마세요.

- 기존의 딕셔너리 형식을 유지하세요.

- 위 기준을 충족하지 못하는 질문만 제거하세요.

- 유효한 질문이 하나도 남지 않은 경우가 아니라면,
  하위 차원 전체 또는 해당 하위 차원의 키를 제거하지 마세요.
