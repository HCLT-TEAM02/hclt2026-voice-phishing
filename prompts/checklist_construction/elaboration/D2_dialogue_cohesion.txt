<태스크 개요>

당신의 임무는 특정 제약 조건에 따라 보이스피싱 증강 대화의 품질을
평가하기 위한 여러 개의 추가 질문을 생성하는 것입니다.

당신에게는 대화 응집성을 평가하기 위한 핵심 구성 요소와 하위 구성 요소,
그리고 이와 관련된 질문이 제공됩니다.

대화 응집성의 정의는 다음과 같습니다:
증강 통화의 발화와 사기 시나리오의 각 단계가 논리적이고 관련성 있게 연결되며,
대화의 주제가 일관되게 유지되는 정도

대화 응집성 차원에 대한 평가는 핵심 구성 요소인
논리적 흐름, 관련성, 단계 전개 연속성, 주제 유지를 중심으로 수행됩니다.


<태스크>

# 당신의 역할:
Seed 이름과 질문의 쌍이 주어졌을 때, 대화 응집성을 고려하여
각 하위 질문을 3개에서 10개의 하위-세부 질문으로 분해해야 합니다.

# 평가 태스크 정보:

평가 태스크 이름:
보이스피싱 증강 통화 품질 평가

평가 목적:
원본 보이스피싱 통화와 이를 바탕으로 생성된 증강 통화를 비교하여,
증강 통화가 원본의 핵심 의미와 사기 전략을 보존하면서
응집성 있고 자연스러운 한국어 통화로 변형되었으며,
원본 대비 충분한 표현 변화를 포함하는지를 평가합니다.

평가 대상 데이터:
- 원본 보이스피싱 통화 1개
- 해당 원본을 바탕으로 생성된 증강 통화 1개

평가 단위:
원본 통화와 증강 통화 한 쌍을 평가합니다.
서로 다른 증강본 1, 2, 3 사이의 상호 다양성은 평가하지 않습니다.

화자 정보:
화자는 S1, S2, S3 등의 번호로만 표시됩니다.
피해자 또는 사기범이라는 역할 정보는 명시적으로 제공되지 않습니다.
필요한 경우 원본 발화 내용을 바탕으로 각 화자의 기능적 역할을 파악해야 합니다.

별도 규칙 기반 검증:
JSON 형식, conversation_id, conversation_label, 필드명, idx 순서,
빈 문자열 여부, 화자 수 및 발화 수 조건과 같은 형식적 규칙은
별도의 프로그램으로 검사합니다.

따라서 이러한 형식적 조건을 평가하는 체크리스트 질문은 생성하지 마십시오.


<하위 차원 및 Seed Questions>

1. 하위 차원: 논리적 흐름
Seed Question: 증강 통화의 각 발화는 앞선 발화에서 논리적으로 이어지는가?

2. 하위 차원: 관련성
Seed Question: 각 발화가 직전 발화의 질문, 설명, 요청 또는 반응에 적절하게 대응하는가?

3. 하위 차원: 단계 전개 연속성
Seed Question: 사기 시나리오의 각 단계가 자연스러운 순서로 제시되는가?

4. 하위 차원: 주제 유지
Seed Question: 대화가 관련 없는 주제로 갑자기 전환되지 않는가?


<제약 조건>

- 각 하위 질문은 간단한 ‘예’ 또는 ‘아니요’로 답할 수 있어야 합니다.

- ‘예’라는 응답은 해당 증강 대화가 명시된 평가 기준을 더 잘 충족한다는 것을 의미해야 합니다.

- 각 질문은 하나의 차원 또는 하나의 개념만을 평가해야 합니다.

- 각 질문은 둘 이상의 주제나 개념을 동시에 묻지 않아야 합니다.


<좋은 평가 질문 목록의 조건>

1. 구체성
각 생성 질문은 Seed Question보다 더 구체적이어야 하며,
Seed Question에 포함된 세부 판단 요소 하나를 명확하게 평가해야 합니다.

2. Seed Question에 대한 추적 가능성
각 생성 질문은 어떤 Seed Question에서 분해되었는지가 명확해야 하며,
Seed Question에 포함되지 않은 새로운 평가 차원이나 관점을 도입하지 않아야 합니다.

3. 세부 요소의 포괄성
생성된 질문들을 종합했을 때 Seed Question의 핵심 평가 내용을
충분히 세분화하여 확인할 수 있어야 합니다.

4. 비중복성
각 생성 질문은 서로 구별되는 세부 요소를 평가해야 하며,
Seed Question이나 다른 생성 질문을 단순히 재진술해서는 안 됩니다.

5. 적절한 세분성 및 판단 가능성
각 질문은 원본 대화와 증강 대화에서 직접 판단할 수 있을 정도로
구체적이어야 하지만, 전체 증강 품질에 거의 영향을 주지 않는
지나치게 사소한 요소까지 분해하지 않아야 합니다.
